- High-quality MP4 video export
- Local processing with an automatically launched backend
- Offline trial and lifetime license activation

## Installation

1. Download `ZynexStudio-Setup.exe` from the official release link above.
2. Run the installer on Windows.
3. Open **Zynex Studio 1.0** using its desktop shortcut.
4. The application starts locally and opens in Google Chrome when available (Microsoft Edge is the fallback).
5. Activate an authorized trial or lifetime license to use the editor.

**Browser and projects:** Use the desktop shortcut and the same browser profile to access saved projects. Browser storage is profile- and address-specific; switching browsers or clearing site data can affect locally saved projects. Keep independent backups of important work when possible.

Internet access is not required for normal local editing and export.
